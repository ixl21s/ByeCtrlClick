A major Gaming Mode update — Metal HUD, Custom Overlay, Performance Mode, App Manager and a brand-new Settings UI.

## What's New

- **Metal Performance HUD** – Overlay your game with real-time FPS, GPU time, CPU time and frame time — directly powered by Apple's Metal framework. Works on macOS 15 and macOS 26.
- **Custom Overlay** – A lightweight in-game overlay showing live CPU, GPU and RAM usage — always on top, fully customizable in position.
- **Performance Mode** – Automatically prevent system sleep, pause Time Machine backups and reduce transparency when Gaming Mode activates — so your Mac stays focused on the game.
- **App Manager** – Add any app to Gaming Mode. All listed apps are automatically closed when Gaming Mode starts and can optionally be relaunched when it ends.

---

## New Settings UI

- Completely redesigned Settings window with a cleaner sidebar navigation, grouped sections and improved visual hierarchy
- All Gaming Mode features — Metal HUD, Custom Overlay, Performance Mode and App Manager — are now neatly accessible in one place
