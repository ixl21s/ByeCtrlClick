# ByeCtrlClick  

**Never again will your left-clicks be interpreted as right-clicks by the Control key.**  

By default, macOS treats every **Control + Left-Click** as a **Right-Click**.  
The result: your character suddenly blocks, aims, or doesn’t react at all – instead of performing the action you intended.  

ByeCtrlClick fixes exactly that:  

- 🚫 Blocks the **Control + Click = Right-Click** shortcut system-wide  
- 🎮 Perfect for games where you need the **Control key together with left-clicks** – whether for attacks, aiming, or special actions  
- 💻 Handy in productivity apps, when you need **Control for shortcuts or custom actions**  
- ⚡ Lightweight, unobtrusive, and optimized for macOS  

---

## ✨ Features

- **Control + Left-Click stays a left-click** – system-wide, in every app and game  
- **Gaming Mode** – prevents camera and mouse stuttering caused by the Magnet app: Magnet is closed automatically while Gaming Mode is on and reopened when you turn it off  
- **Hide App Icon** – removes the Dock icon so ByeCtrlClick runs quietly in the background  
- **Menu bar app** – Settings, Repeat Onboarding, Allow Access, Check for Updates and Quit are always one click away  
- **Guided onboarding** – walks you through the setup and can be replayed at any time  
- **macOS Tahoe 26 ready** – new Glass UI and SF Symbols in the menu bar  
- **English and German** interface  

---

## 🚀 Getting Started

1. Download the latest `.dmg` from [updates.byectrlclick.com](https://updates.byectrlclick.com).  
2. Open the `.dmg` and drag **ByeCtrlClick** into your **Applications** folder.  
3. Launch ByeCtrlClick and follow the onboarding.  
4. Grant **Accessibility** access when asked (*System Settings → Privacy & Security → Accessibility*). ByeCtrlClick adds itself to the list automatically – just switch it on.  
5. Activate your license – done. Control + Left-Click is now a real left-click.
